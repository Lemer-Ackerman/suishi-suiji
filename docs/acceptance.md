# 验收约定

1. 启动时默认置顶。主界面只有消息区、输入框和更多菜单；日历在右上角「⋯」菜单中。
2. Enter 发送，Shift + Enter 换行。写入真实磁盘成功后才清空输入框；每条记录显示秒级时间。
3. 日历选日期后看到对应聊天记录；未发送、空白内容和无记录日期不创建文本文件。
4. 凌晨 03:59 属于前一天，04:00 打开新日期；已发送记录保持不变。跨月、跨年、闰日和夏令时正确。
5. 单条及整天复制写入系统剪贴板；删除弹窗取消时保留文件，确认时移除相应记录，最后一条删除时移除文件。
6. 隐藏或关闭后进程继续运行；快捷键可召出或隐藏，设置重新启动后保留。冲突不得撤销原快捷键。
7. Windows 默认 D:\Daynote，不可用时提示选择；macOS 默认文稿/Daynote。自定义路径复制历史，不覆盖冲突，保留原文件。
8. 磁盘失败不得清空输入或显示发送成功；路径穿越、无效日期和超大文本被拒绝。
9. 自动化测试使用独立临时目录。测试时钟只在开发模式生效。文件选择器返回临时路径，实际文件读写和持久化不替换。
10. 强制结束后恢复已保存草稿；发送提交后中断不重复，草稿不生成日记文本文件。
11. 生成 Windows 安装包/便携版与两个 macOS 架构包，发布到正确的公开仓库。

验证入口：`npm run check`、`npm test`、`npm run test:e2e`、GitHub Actions 双系统构建。注册成功不等于完整快捷键验收，实际键盘唤出/隐藏需要系统级测试。

编辑验收：图标具备文字提示；保存保持原时间、ID、排序；取消/空白不改原记录；重开保留修改；编辑草稿强制结束后恢复；写入失败可重试；凌晨跨日仍修改原日期；过期内容不能覆盖新的文件内容。
