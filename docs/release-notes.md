日笺的第一个版本：一个默认置顶的聊天式桌面记事窗口。

- 每条记录显示到秒，Enter 发送、Shift + Enter 换行。
- 右上角「⋯」打开日历，按日期查看历史；凌晨 4 点自动翻页。
- 默认 Shift + 空格 显示/隐藏，可自定义。
- 单条与整天复制、删除；删除必须确认。
- 无记录不创建文本文件，Windows 默认 D:\Daynote，支持自定义文件夹。
- 支持开机自动启动开关；开启后登录电脑时后台运行。

下载：Windows 选择 setup.exe 安装版或 portable.exe 免安装版；M 系列 Mac 选择 arm64.dmg，Intel Mac 选择 x64.dmg。ZIP 是 macOS 备用包。安装后再开启自启动，应用移动位置后请重新设置。

应用未使用商业开发者证书签名或 Apple 公证，首次打开可能有系统提示。macOS 如被拦截，可在“系统设置 → 隐私与安全性”确认允许此应用；Windows 可能显示 SmartScreen 提示。

构建在 Windows、macOS 上通过规则测试和真实桌面流程测试，并检查打包产物。提供 SHA256SUMS.txt 校验文件。笔记仅保存在本地，未发送草稿不会写入文件。
