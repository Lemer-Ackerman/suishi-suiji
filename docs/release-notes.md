v1.1.0：已发送的记录现在可以编辑。

- 每条记录下方使用复制、编辑、删除图标，悬停显示操作名称。
- 点击铅笔修改内容，保存后保留原始记录时间、顺序和所属日期。
- 编辑支持多行，Enter 换行，Ctrl / ⌘ + Enter 保存；取消保留原文。
- 编辑草稿自动保存，意外退出后恢复，不影响输入框中未发送的新消息。
- 写入失败时保留原记录和修改内容；记录在其他地方被改动时阻止覆盖。
- 删除仍需确认，原有快捷键、日历、开机启动和保存位置设置保持兼容。

Windows 选择 setup.exe 安装版或 portable.exe 免安装版；M 系列 Mac 选择 arm64.dmg，Intel Mac 选择 x64.dmg。ZIP 为 macOS 备用包。

未使用商业开发者证书签名或 Apple 公证，首次打开可能出现系统提示。提供 SHA256SUMS.txt 校验文件。
